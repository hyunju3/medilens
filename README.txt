메디렌즈 설치형 웹앱 (PWA)

메디링고와 같은 방법으로 설치해요. (프로젝트 문서 '메디링고 앱 설치 방법' 참고)

[GitHub Pages에 올리기 — 무료]
1. github.com 로그인 → 오른쪽 위 + → New repository → 이름: medilens → Public → Create repository
2. "uploading an existing file" → 이 폴더 안의 파일 전부 업로드
   (index.html, sw.js, manifest.webmanifest, 아이콘 png 4개) → Commit changes
3. Settings → Pages → Branch: main, 폴더 / (root) → Save
4. 1~2분 뒤 https://아이디.github.io/medilens/ 주소가 생겨요

[갤럭시에 설치]
크롬으로 위 주소 열기 → 오른쪽 위 ⋮ → '앱 설치'(또는 '홈 화면에 추가')

[용어가 추가되면]
새 index.html만 같은 저장소에 다시 올리면 돼요(덮어쓰기). 앱을 껐다 켜면 새 버전으로 바뀌어요.
※ 즐겨찾기·최근 기록은 그 휴대폰 안에만 저장돼요.
